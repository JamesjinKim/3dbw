1. 시작하기 전에

진동센서 1대에 포토센서 1개

진동센서마다 자기 포토센서가 짝을 이룹니다. 각 짝은 서로 완전히 독립적으로 동작합니다 — 1번이 수집 중이어도 2번은 대기 상태일 수 있고, 두 대가 겹쳐 수집할 수도 있습니다. 

진동센서 1 ── 포토센서 1(DIN1) 불 켜짐 → 센서 1만 정해진 시간 수집 → 저장 → 대기
진동센서 2 ── 포토센서 2(DIN2) 불 켜짐 → 센서 2만 정해진 시간 수집 → 저장 → 대기

고정 장치 이름 — 어느 센서인지 헷갈리지 않게

같은 종류의 진동센서 두 대는 소프트웨어로 구분할 방법이 없습니다. USB 브리지칩에 고유 일련번호가 없고, 데이터 자체에도 장비 식별자가 없기 때문입니다. 구분할 수 있는 것은 어느 USB 구멍에 꽂혔는가 하나뿐입니다.

그런데 리눅스가 붙이는 /dev/ttyACM0, /dev/ttyACM1 번호는 꽂는 순서와 재부팅에 따라 바뀝니다. 그래서 이 프로그램은 USB 구멍마다 변하지 않는 이름을 만들어 씁니다. 윈도우에서 “이 장치는 항상 COM3” 으로 고정해 두는 것과 같은 개념입니다. 

/dev/iis3dwb1   →  1번 구멍에 꽂힌 센서 (항상)
/dev/iis3dwb2   →  2번 구멍에 꽂힌 센서 (항상)

실행 — 명령은 bash run.sh 하나입니다

인터넷(폐쇄망)은 필요 없습니다. 시리얼 라이브러리(pyserial)는 패키지의 vendor/ 에 들어 있습니다. 받은 zip 을 풀면 나오는 iis3dwb-collector-<버전> 폴더를 홈 폴더 등에 복사하고, 그 폴더에서 bash run.sh 를 실행합니다. 설치 단계가 따로 없습니다. 

cd iis3dwb-collector-<버전>
bash run.sh
언제run.sh 가 하는 일
처음 실행 환경을 점검하고, 빠진 USB·포토센서 권한(udev 규칙·사용자 그룹)을 설정한 뒤 명령을 실행합니다. 이때 관리자 비밀번호를 물을 수 있습니다. 화면(데스크톱)의 터미널에서는 재로그인 없이 바로 쓸 수 있습니다.
두 번째부터 점검만 하고 바로 실행합니다. 비밀번호를 묻지 않습니다. 바탕화면의 SHT 진동센서 수집 아이콘을 더블클릭해도 됩니다 (“실행할까요?” 를 묻는 창이 뜨면 실행).
옵션 없이 bash run.sh 수집기 화면(GUI)이 뜹니다 (2장). 화면이 없는 라즈베리파이(Lite·SSH)에서는 글자 화면으로 자동 수집을 시작합니다.
./run.sh 가 아니라 bash run.sh 로 실행하세요. USB 메모리(FAT 포맷)를 거쳐 복사하면 실행권한이 사라져 ./run.sh 는 “허가 거부” 가 납니다. bash run.sh 는 권한과 상관없이 동작합니다.

SSH 로 접속해 쓰는 경우: 처음 실행에서 권한을 설정한 뒤 한 번 로그아웃했다가 다시 접속해야 적용됩니다. 새 버전으로 바꿀 때: 옆 폴더에 풀고 그 폴더에서 bash run.sh 를 실행하면 됩니다. 센서 번호·포토센서 배정은 버전과 상관없이 그대로 남습니다.

센서 번호 정하기 — 처음 한 번만

진동센서를 모두 꽂고 수집기 화면의 [센서 번호 지정] 을 누릅니다. USB 구멍 순서대로 센서 1, 2 … 를 붙이고 포토센서 DIN1, DIN2 … 와 짝지을 목록을 보여 주고, 예를 누르면 저장합니다. 진동센서 1번이 목록 첫 줄의 구멍에 꽂혀 있어야 포토센서 1번과 짝이 맞습니다.

고정 장치 이름(/dev/iis3dwb1)은 관리자 권한이 필요해 터미널에서 한 번 만듭니다. 글자 화면만 쓸 때는 번호 지정도 터미널에서 합니다. 

# 번호 지정 (화면의 [센서 번호 지정] 과 같음)
bash run.sh slots --auto

# 고정 이름을 만든다 (관리자 비밀번호를 물을 수 있음, 한 번만 · 권장)
bash run.sh slots --make-udev

# 확인
bash run.sh slots

확인하면 이렇게 나옵니다.

이름   고정 장치 이름        현재 장치       USB 포트     포토센서
1      /dev/iis3dwb1      /dev/ttyACM0   usb-0:1.2    DIN1
2      /dev/iis3dwb2      /dev/ttyACM1   usb-0:1.3    DIN2

재부팅해도, 케이블을 뽑았다 꽂아도 고정 이름은 그대로입니다. 현재 장치 쪽 번호는 바뀔 수 있지만 상관없습니다.

어느 구멍이 몇 번인지 잊었다면 아무 때나 확인할 수 있습니다. 포트에 스티커를 붙일 필요가 없습니다. 
ls -l /dev/iis3dwb*
케이블을 다른 구멍으로 옮기면 번호가 바뀝니다. 고정되는 것은 “센서”가 아니라 “구멍”이기 때문입니다. 센서를 교체할 때는 같은 구멍에 꽂으세요. 구성을 바꿨다면 [센서 번호 지정](과 고정 이름 만들기)을 다시 하면 됩니다.

포토센서 활성 레벨

아무 입력이 없을 때 DIN 핀은 HIGH로 읽힙니다. 산업용 포토센서는 대개 NPN 출력이라 감지되면 신호를 GND로 끌어내리므로 활성 레벨은 LOW가 기본입니다. PNP 출력이면 수집기 화면의 공통 설정 → 포토센서 활성 레벨을 HIGH (PNP) 로 바꾸세요 (글자 화면은 --active high).

센서 칸의 포토센서 표시(● HIGH — 대기 / ● LOW — 감지)가 실시간으로 바뀌므로 바로 확인됩니다. 포토센서에 불이 들어왔을 때 ‘감지’가 되어야 맞습니다. 반대로 보이면 활성 레벨을 바꾸세요.

글자 화면 (화면이 없는 라즈베리파이)

Lite 이미지나 SSH 처럼 화면이 없으면 bash run.sh 가 글자 화면으로 자동 수집을 시작합니다. 옵션으로 직접 고를 수도 있습니다. 끝낼 때는 Ctrl+C. 옵션을 주지 않은 항목은 수집기 화면에서 저장한 설정을 씁니다.

# 상태만 확인 — 센서·슬롯 이름·수집 가능 여부
bash run.sh --status

# 공정 운영 — 포토센서가 감지될 때마다 그 센서만 기록
bash run.sh --auto

# 지금 바로 두 센서 모두 기록 (포토센서 없이)
bash run.sh --manual --minutes 1

# 기록 없이 실시간 상태만 보기 (배선·포토센서 확인용)
bash run.sh --watch
옵션뜻기본
--minutes N / --seconds N한 번에 기록하는 길이저장된 설정 (처음 5분)
--fmt csv|bin저장 형식 (3장)저장된 설정 (처음 csv)
--out 폴더저장 폴더저장된 설정 (처음 ~/vibdata)
--active low|high포토센서 활성 레벨 (1장)저장된 설정 (처음 low)
--only 이름--manual 에서 한 센서만—

안내와 경고의 차이

ℹ 센서 1대가 인식되었습니다 — 안내입니다. 한 대만 꽂고 쓰는 것은 정상 운영입니다. 그대로 수집하시면 됩니다.
⚠ 이름이 지정되지 않은 USB 슬롯이 있습니다 — 이때는 시작되지 않습니다. 어느 센서인지 모르는 데이터를 엉뚱한 이름으로 기록하면 나중에 되돌릴 수 없기 때문에 일부러 막습니다. 화면의 [센서 번호 지정](글자 화면은 bash run.sh slots --auto)으로 번호를 먼저 정하세요 (1장).

run_NNNN.json — 수집 정보

분석 전에 아래 세 항목을 먼저 보세요.

항목정상뜻
loss_pct0 전송 중 빠진 패킷 비율. 0이 아니면 데이터에 구멍이 있습니다.
queue_drops0 기록이 밀려 버린 패킷 수. 0이 아니면 디스크가 느린 것입니다.
shortfallnull 받은 양이 기대치에 못 미침. 값이 있으면 수집이 온전하지 않습니다.

그 밖에 rate_hz(샘플레이트), full_scale_g(측정 범위), started/ended(시각), actual_seconds(실제 수집 길이)가 들어 있습니다.

4. 데이터 단위 — 스케일은 이미 적용돼 있습니다

CSV의 _mg 열은 이미 환산이 끝난 값입니다. 별도의 스케일 연산이 필요 없습니다. 그대로 쓰시면 됩니다.

CSV 열 설명

recv_iso,seq,timestamp_ms,sample_idx,x_raw,y_raw,z_raw,x_mg,y_mg,z_mg
2026-09-23T12:55:17.996,6,4200,0,-571,-412,8001,-69.66,-50.26,976.12
열뜻
recv_iso기록 시각
seq패킷 순번. 건너뛰면 그 구간이 유실된 것입니다.
timestamp_ms센서 부팅 후 경과 시간(ms). 지터가 없어 시간축으로 쓰기 좋습니다.
sample_idx그 패킷 안에서의 순번 (0~199)
x_raw, y_raw, z_raw센서 원시값 (16비트 정수, 단위 LSB)
x_mg, y_mg, z_mg 환산된 가속도 (mg). 분석에는 이 열을 쓰세요.

환산이 어떻게 되는가

스케일을 정하는 것은 측정 범위(±2/4/8/16 g)이지 샘플레이트가 아닙니다. 범위 값은 데이터 패킷 안에 함께 실려 오므로 수집기가 자동으로 맞는 감도를 적용합니다. SHT 진동센서 설정에서 ±8g를 ±4g로 바꾸셔도 사용자가 할 일은 없습니다.

측정 범위감도
±2 g0.061 mg/LSB
±4 g0.122 mg/LSB
±8 g0.244 mg/LSB
±16 g0.488 mg/LSB

원시값을 직접 쓰실 때

mg    = raw × 감도                 (위 표)
g     = mg / 1000
m/s²  = g × 9.80665
측정 범위를 넘는 진동은 잘려서 기록됩니다(클리핑). _raw 값이 ±32767에 붙어 있다면 범위를 키워 다시 측정하세요. 반대로 범위가 너무 크면 미세 진동의 분해능이 떨어집니다.

5. 샘플레이트 선택 — 꼭 읽어 주세요

주파수 분석(FFT)이 목적이라면 26.6 kHz로 수집하세요. 그보다 낮은 설정은 실제로 존재하지 않는 저주파 성분을 만들어 냅니다.

이유

이 센서는 출력 속도가 26.667 kHz로 하드웨어 고정입니다. 1 kHz나 3.3 kHz를 고르면 센서가 느리게 도는 것이 아니라, 펌웨어가 N개 중 1개만 골라내는 방식입니다. 

26.6 kHz 선택 →  ●●●●●●●●●●●●●●●●   전부 사용
 3.3 kHz 선택 →  ●・・・・・・・●・・・・・・・   8개 중 1개만 사용 (저역통과 필터 없음)

신호를 솎아내기 전에 저역통과 필터를 거치지 않기 때문에, 새 나이퀴스트 주파수를 넘는 성분이 사라지지 않고 낮은 주파수 자리로 접혀 들어옵니다. 이것을 에일리어싱(aliasing)이라고 합니다.

접힌 뒤 나타나는 자리는 다음 식으로 계산됩니다. 실제 진동 주파수를 f, 고른 샘플레이트를 fs라 할 때 

기록되는 주파수 = | f − (f / fs 를 반올림한 정수) × fs |
영향의 크기는 측정 대상이 어떤 주파수로 진동하는지에 따라 다릅니다. 높은 주파수 성분이 거의 없는 기계라면 영향이 작지만, 있으면 낮은 주파수 자리로 접혀 들어옵니다.

어떤 설정을 고를까

설정나이퀴스트주파수 분석전체 진동량(RMS·피크)
26.6 kHz13.3 kHz 정확 ✅정확
13.3 kHz6.67 kHz경계 — 주의정확
6.6 kHz3.3 kHz접힘 발생 ⚠정확
3.3 kHz1.67 kHz접힘 큼 ⚠정확
1 kHz500 Hz접힘 가장 큼 ⚠정확
RMS·피크 같은 전체 진동량만 보신다면 낮은 레이트도 괜찮습니다. 문제가 되는 것은 “몇 Hz에서 진동하는가”를 따질 때입니다.

권장 방법

항상 26.6 kHz로 수집하고, 분석 단계에서 필요한 대역만 추출하십시오. 용량이 부담되면 바이너리 형식을 쓰면 1/11.6로 줄어듭니다. 

# 올바른 다운샘플링 — 필터를 먼저 거칩니다
from scipy.signal import decimate
z_3k = decimate(z_mg, 8, ftype='fir', zero_phase=True)   # 26.6kHz → 3.3kHz

진동 크기 (RMS·피크)

import numpy as np
d  = np.loadtxt("run_0012.csv", delimiter=",", skiprows=1, usecols=(7,8,9))
ac = d - d.mean(axis=0)                    # 중력(DC) 성분 제거
rms  = np.sqrt((ac**2).mean(axis=0))       # 축별 RMS [mg]
peak = np.abs(ac).max(axis=0)              # 축별 피크 [mg]
print("RMS  X %.1f  Y %.1f  Z %.1f mg" % tuple(rms))
print("Peak X %.1f  Y %.1f  Z %.1f mg" % tuple(peak))

중력은 항상 약 1000 mg의 DC 성분으로 들어 있습니다. 진동만 보려면 위처럼 평균을 빼세요.

주파수 스펙트럼 (26.6 kHz 수집분에서만)

fs = m["rate_hz"]                          # json 에서 읽는다
z  = ac[:, 2]                              # Z축
n  = len(z)
spec = np.abs(np.fft.rfft(z * np.hanning(n))) * 2 / n
freq = np.fft.rfftfreq(n, 1/fs)
top = freq[np.argsort(spec)[-5:]][::-1]
print("주요 주파수:", np.round(top, 1), "Hz")
